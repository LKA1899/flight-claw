FlightClaw Web 控制台高保真原型

定位为个人机票监控 Workflow 控制台。界面强调资源管理、任务执行链路、低频本地浏览器查询、截图/HTML 可追溯、人工接管与报告分析。

完整信息架构

  • Overview：总览仪表盘

  • Workflows：工作流定义
  • Workflow Runs：执行记录
  • Query Tasks：浏览器查询任务
  • Price Results：原始价格结果
  • Reports：分析报告
  • Settings：本地运行参数

页面之间的跳转关系与交互说明

Run Workflow点击后创建 Workflow Run 与 Batch，进入 Workflow Run Detail，顶部显示 RUNNING。Overview / Workflows → Run Detail
Run Task打开本地有头浏览器，串行执行 CTRIP 查询；验证码或登录态异常时进入人工接管状态。Query Tasks → Local Browser
Screenshot / HTML点击后查看已保存页面快照或 HTML，用于追溯查询结果和调试解析器。Query Tasks / Price Results → Snapshot
Parse Price只读取已保存 HTML，不重新访问 OTA；解析结果写入 Price Results。Query Tasks → Price Results
Report从 Workflow Run、Batch、Price Results 进入分析报告，查看今日综合最优、稳妥方案和风险说明。Overview / Reports → Report Detail
Monitor Dates在 Monitor 列表或详情页进入日期管理，启用、禁用或批量生成查询日期。Monitors → Monitor Detail / Dates

字体、间距和密度
  • 字体：Inter / Segoe UI / Microsoft YaHei，正文 14px，表格 13px，标题 18-28px。
  • 页面宽度：1440px desktop first，主内容 padding 24px，卡片间距 16px。
  • 圆角：卡片和输入 8px，按钮 7px，Tag/Badge 12px。
  • 表格密度：表头 42px，普通行 56px，高密度但保留可读性。
  • 边框：#E5EAF2，轻阴影仅用于主卡片，不使用花哨渐变。
按钮层级
  • 主按钮：Run Workflow、Create Monitor、Run Monitor、Send Notification。
  • 次按钮：View、Edit、Dates、Schedule、Screenshot、HTML。
  • 危险按钮：Reset、Delete，用红色文字和浅红边框。
  • Disabled：第一版 New Workflow、Retry Failed Step 可以禁用。
实现建议
  • 优先抽出 StatusBadge、StrategyTags、RiskBadge、WorkflowStepNode、RouteCell、PriceTrend、SnapshotLinks。
  • 列表页统一使用 Filters + Batch Actions + Dense Table。
  • 详情页统一使用 Summary Cards + Timeline/List + Context Side Panel。
  • Workflow Run Detail 按 CI/CD 日志视角实现，错误 Alert 必须置顶。
  • 本地浏览器和安全策略在 Header、Task Alert、Settings 中持续可见。
